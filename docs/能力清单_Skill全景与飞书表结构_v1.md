## 二、飞书表字段结构方案（MVP精简版：2张表）

### 2.1 表1：能力表（Skill全景）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| Skill名称 | 文本 | 唯一标识 |
| 一句话定义 | 文本 | 它是什么（15字以内） |
| 解决什么问题 | 长文本 | 痛点描述 |

| 成熟度 | 单选 | 待探索 / 试用中 / 已验证 / 已淘汰 / 未核实-建议剔除 |
| 电商维度 | 多选 | 流量获取 / 商品运营 / 内容生产 / 数据分析 / 团队效率 / 学习成长 |
